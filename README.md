## Mandarin Playgroup

**A community platform connecting 140+ Bay Area families so kids can hear and use Mandarin naturally through play.**

I built the product end-to-end using an **AI-native development workflow**, combining customer discovery, product strategy, lightweight infrastructure, automation, and AI-powered product capabilities.

The product includes:

- 🌐 A production website deployed with **Cloudflare Pages and GitHub CI/CD**
- 👨‍👩‍👧‍👦 A community platform connecting **140+ Bay Area families**
- 📅 A family activity calendar aggregating **70+ events from 10+ sources**, refreshed automatically twice daily
- 🤖 An AI-powered calendar assistant that lets parents **type or speak natural-language questions** and retrieves live event data before responding
- 🔎 An autonomous LLM-powered event discovery agent that **discovers, evaluates, validates, and publishes** relevant Mandarin and Chinese cultural events
- 🧠 Structured event data using **Schema.org**, plus `llms.txt` and AI crawler configuration to improve AI discoverability
- ⚙️ Automated community onboarding, communications, event refresh, and publishing workflows
- 💰 Explicit AI call and spending caps to keep operating costs predictable while validating demand
- ☁️ Lightweight infrastructure designed to minimize complexity and ongoing cost

The project reflects how I approach 0→1 product development:

**Start with a real customer problem → build the simplest useful product → validate demand → automate what creates leverage → use AI where it improves the experience or operating model.**
